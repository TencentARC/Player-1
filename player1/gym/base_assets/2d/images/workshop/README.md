# Fieldcraft workshop artwork

Kenney UI Pack – Pixel Adventure supplies the panel, paper and slot frames; Generic Items supplies the recipe-book image. Their original CC0 license files are included. `items.svg` contains one named, padded cell for each of the 52 current item IDs, with separate tool/armor material palettes, ore/ingot and raw/cooked identities. The avatar and cursor are original editable SVG artwork. `SOURCES.json` records file provenance; runtime uses ordinary asset preload.
