# Pixel2Play protobuf bindings

These generated bindings are copied from `elefant-ai/open-p2p` at commit
`a329d98cbe62119679a254d71bea6446773541bc`. They decode the source-native
`annotation.proto` payload without importing the upstream training package.

The upstream MIT license is preserved in `LICENSE`. Generated files are excluded
from Ruff; adapter and schema tests cover their use.
